# Roblox Teleport Button

This project contains a script to create a teleport button in Roblox Studio. It is designed for Roblox Runner Delta and allows players to teleport slightly forward to cross walls.

## Install

1. Open Roblox Studio.
2. Create a new script in ServerScriptService.
3. Copy the contents of `src/TeleportButton.lua` into the script.

## Use

1. Run the game.
2. Click the teleport button to move forward.
